# Phrasal verbs practice

Интерактивное задание для взрослых: 16 ситуаций с выбором одного из двух фразовых глаголов, объяснения на русском, результаты и повтор ошибок.

Откройте `index.html` в браузере. Установка и сборка не нужны.

Клавиши `1` и `2` выбирают ответ. Интерфейс адаптирован для телефона и компьютера.
